# Johnny Muscles Camera Pass 0.2

- Increased maximum sling pull from 245 to 360 world units.
- Camera eases backward while aiming to create more drag room behind the tank.
- Camera follows the thrown tank forward with no positive-distance cap.
- Removed the old forward-distance auto-reset.
- Added an endless procedural skyline and scrolling ground stripes so long throws never expose an empty canvas.
- Pointer coordinates now convert through the current camera offset.
