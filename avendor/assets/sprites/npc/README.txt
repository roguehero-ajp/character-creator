NPC SPRITES

Named residents are grouped first by settlement and then by canonical character
id. NPCs use the shared Hero Rig 0.4.0 frame cell and direction rows. A stationary
resident may ship with idle.png only; the sprite engine holds that idle frame if
the NPC has no walk atlas.
