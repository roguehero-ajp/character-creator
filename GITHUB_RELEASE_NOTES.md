# My RPG Source v1.0.0 — First Public Release

My RPG Source v1.0.0 is the first feature-complete public release of the browser-based D&D 5e character builder.

## Highlights

- D&D 5e 2014 and 2024 support
- All twelve SRD classes
- Structured class and subclass features
- Level Up, multiclass-aware character totals, and structured feats
- Dynamic class-aware spellcasting
- Smart caster profiles for every SRD spellcasting class
- Multiclass spell slots, Pact Magic, Mystic Arcanum, and subclass magic
- Edition-aware equipment and combat helpers
- Save/load, autosave, JSON import/export, printing, and PDF export
- Contextual Knowledge Cards with optional disable switch
- Integrated searchable Rules Codex with **2,630 validated versioned entries**
- Responsive themes and print-aware generated continuation pages

## Data

- **319** unique SRD spells in the 2014 builder dataset
- **338** unique SRD spells in the 2024 builder dataset
- **422** edition-specific class/subclass feature Codex entries
- **2,630** total validated versioned Codex entries

## Compatibility

The application version is now **1.0.0**.

The character save schema remains **SAVE_VERSION 2**, preserving compatibility with existing supported local saves and JSON backups.

## What Comes Next

Post-1.0 work will focus on stricter class-choice selectors, class resource trackers, proficiency-source tracking, the fully guided multiclass Level Up branch, additional spell/feat edge automation, accessibility/mobile/print polish, and the planned My First Steps beginner experience.
